# Election Navigator AI 🗳️

**Production-Grade AI Civic Platform**

Election Navigator AI is an advanced, scalable civic education and election-process guidance platform. It serves as a "Digital Twin" of the voting process, providing personalized, neutral, and trusted guidance to citizens.

---

## 🚀 Vision
Our mission is to reduce disenfranchisement by providing clear, accessible, and high-quality civic data through advanced AI reasoning.

---

## 🏗️ Core Architecture
- **Next.js & TypeScript:** High-performance frontend with premium UI/UX.
- **Gemini 2.5 Pro:** Advanced LLM for localized civic data extraction and reasoning.
- **Google Cloud Platform:**
  - **Cloud Run:** Scalable compute.
  - **Firestore:** Real-time persistence.
  - **BigQuery:** Secure analytics.
  - **Vertex AI:** Enterprise-grade AI orchestration.

---

## ✨ Key Features
- **Civic Digital Twin**: Interactive, state-aware process maps of voter journeys.
- **AI Trust Framework**: Real-time transparency metrics (Accuracy, Clarity, Bias Risk).
- **Scenario Simulation**: "What-if" educational simulations for complex election events.
- **Risk Monitoring**: Automatic detection of procedural misunderstandings and deadlines.
- **Universal Accessibility**: Fully responsive, touch-friendly, and WCAG-compliant design.

---

## 🛠️ Getting Started
1. Clone the repository.
2. `npm install`
3. Set your `GEMINI_API_KEY` in `.env.local`.
4. `npm run dev`
5. Visit `http://localhost:3000`.
